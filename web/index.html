💬

多轮对话

自动维护上下文记忆，支持流式打字机输出，兼容 reasoning 模型的思考过程。

🎨

文生图 / 图像编辑

一句描述生成图片；双通道兼容 images 端点与聊天式图像模型，支持局部重绘。

👁

图像理解

上传本地图片或 URL，让视觉大模型为你解读内容、提取信息、回答提问。

🔊

语音合成 / 识别

文本转自然语音（TTS），音频转文字（STT），支持多种音色。

🌐

翻译 / 摘要 / 改写

多语言互译、长文摘要、风格改写、信息抽取、文本分类，开箱即用。

🛠

Function Calling

注册 Python 工具函数即可构建 Agent，自动完成“调用→执行→回传”循环。

🧮

向量化 Embedding

文本转向量，为检索增强（RAG）、聚类、相似度搜索提供基础能力。

💻

代码生成

按需求生成 Python / JS 等代码，并可通过工具循环自动运行与自我修正。

Python SDK

from imageai import ImageAI
ai = ImageAI()                      # 自动读取 .env 配置，直连真实大模型
print(ai.chat("你好，介绍一下你自己"))
ai.generate_image("赛博朋克风格的猫")
print(ai.translate("床前明月光", target_lang="英文"))

启动本页服务

cp .env.example .env   # 填入 IMAGEAI_API_KEY / BASE_URL / MODEL
python app.py          # 打开 http://localhost:8000 即为本主页
